# BRGroupWare

휴가를 한 번 신청하면 팀장 결재부터 팀 일정 반영까지 끝나는 그룹웨어 프로토타입입니다.
해커톤 계획은 [docs/BRGroupWare_해커톤_계획서.md](docs/BRGroupWare_해커톤_계획서.md)에 있습니다.

## 1분 만에 실행하기

준비물: Python 3.7 이상 (설치 확인: `python --version`)

1. 터미널(PowerShell)을 열고 이 폴더로 이동합니다.

   ```powershell
   cd BR_GroupWare
   ```

2. 서버를 켭니다.

   ```powershell
   python -m http.server 8000 -d app
   ```

3. 브라우저에서 **http://localhost:8000** 을 엽니다.

끌 때는 터미널에서 `Ctrl + C`를 누릅니다.

| 이럴 때 | 이렇게 |
| --- | --- |
| `Address already in use` / 포트 사용 중 | 숫자만 바꿔서 실행: `python -m http.server 8080 -d app` 후 http://localhost:8080 |
| `python`을 찾을 수 없음 | `py -m http.server 8000 -d app` 로 실행 |
| 코드를 고쳤는데 화면이 그대로 | 브라우저에서 `Ctrl + F5` (강력 새로고침) |
| Python 대신 Node.js가 있음 | `npx serve app` |

빌드, 설치, DB 모두 필요 없습니다. 데이터는 브라우저 localStorage에 저장됩니다.

## 시연 순서

로그인 대신 오른쪽 위 **정다은 팀원 / 박지훈 팀장** 버튼으로 보는 사람을 바꿉니다.

1. **정다은 팀원**으로 홈을 엽니다. 제목에 "12월 3일 연차가 박지훈 팀장 결재를 기다리고 있습니다"가 보이고, 결재란 팀장 칸은 비어 있습니다.
2. **박지훈 팀장**으로 바꿉니다. '내가 처리할 일' 맨 위에 정다은 연차가 있고, 바로 아래에 그날 팀 일정(14:00 주간 해외사업 회의)이 함께 보입니다. 캘린더를 따로 열 필요가 없습니다.
3. **승인**을 누릅니다. 아래 '팀 일정' 12/3 칸에 정다은 연차가 바로 생깁니다.
   반려하려면 **반려**를 누르고 사유를 적어야 버튼이 눌립니다.
4. 다시 **정다은 팀원**으로 바꿉니다. 결재란에 팀장 도장이 찍히고, 제목이 "승인됐습니다"로 바뀝니다.

다시 처음부터 하려면 왼쪽 메뉴 맨 아래 **시연 데이터 초기화**를 누릅니다.

**두 창 시연:** 브라우저 창을 두 개 띄워 한쪽은 팀원, 한쪽은 팀장으로 두면 팀장이 승인하는 순간 팀원 창에 도장이 찍힙니다. (보는 사람은 창마다 따로 기억합니다.)

## 홈 화면 구성

| 영역 | 누구에게 | 내용 |
| --- | --- | --- |
| 제목 | 모두 | 팀원은 내 휴가가 어디까지 갔는지, 팀장은 처리할 일 건수 |
| 내 휴가 신청 | 팀원 | 신청 건과 결재란(신청자 서명, 팀장 도장), 진행 상태 |
| 내가 처리할 일 | 모두 | 결재, 협조 요청. 휴가 건에는 그날 팀 일정과 다른 휴가자가 같이 보임 |
| 팀 일정 | 모두 | 이번 주와 다음 주, 팀원별로 승인된 휴가만 표시 |
| 오늘 | 모두 | 오늘 내 일정 타임라인, 빨간 선이 현재 시각 |
| 공지 | 모두 | 최근 공지 3건 |

## 데이터 모양

localStorage 키 `brgw` 하나에 모두 들어 있습니다. 휴가 신청 레코드가 전자결재와 일정을 잇습니다.

```js
{
  id: "L1",
  신청자: "jde",          // PEOPLE 키 (app.js 맨 위)
  종류: "연차",
  날짜: "2026-12-03",
  사유: "개인 일정",
  결재자: "pjh",
  상태: "대기",           // "대기" → "승인됨" | "반려됨"
  신청일: "2026-11-25",
  처리일: "",
  반려사유: ""
}
```

상태가 `승인됨`이면 그 레코드가 그대로 팀 일정에 보입니다. 일정을 따로 만들지 않습니다.
데이터를 직접 보려면 브라우저 개발자 도구(F12) > Application > Local Storage를 엽니다.

## 아직 비어 있는 것

- 휴가 신청, 결재 상세, 팀 일정 화면은 메뉴 자리만 있습니다 (계획서 6번 '화면' 담당).
- 오늘 일정은 매일 같은 샘플입니다 (`app.js`의 `DAILY`).
- 시연 데이터 날짜는 2026년 11~12월로 고정돼 있습니다. 다른 날 시연하면 `app.js`의 `seed()` 날짜를 바꿉니다.
